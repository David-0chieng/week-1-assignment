Glossary

Element
A start tag, its content and an end tag, such as <p>Hello</p>.
Attribute
Extra information inside a start tag, like href, src or alt.
Selector
The part of a CSS rule that chooses which elements to style.
Box Model
Content, padding, border and margin: the four layers around every element.
